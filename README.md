# Flipper OS 2.0

Собственная прошивка для Flipper Zero, написанная с нуля и заточенная под исследование
Sub-GHz: спектр, поиск частоты, запись и разбор сигналов, распознавание протоколов,
повтор собственных записей. Проект для личного использования.

Это не форк официальной прошивки. Официальный репозиторий использовался только как
справочник по железу (распиновка, значения регистров). BLE, NFC, RFID, IR, iButton, USB и
приложения `.fap` не поддерживаются — так задумано.

> **Статус.** Вся логика, не зависящая от железа, проверена на ПК: модульные тесты, тесты
> на реальных записях, сквозные тесты в симуляторе. Аппаратная часть (`platform/stm32wb55`)
> собирается без предупреждений, но **на реальном устройстве ещё не запускалась**. Первую
> прошивку делайте по чек-листу в конце этого файла.

## Возможности

| Экран | Что делает |
|---|---|
| Receiver | приём на частоте или с перебором частот, декодирование на лету, история, сохранение и повтор |
| Spectrum | развёртка уровня сигнала, полоса от 1 до 50 МГц, удержание пиков, переход в приёмник на пике |
| Frequency finder | определяет частоту брелока: грубый проход по списку частот и точная подстройка |
| RAW recorder | запись импульсов на SD в формате `.sub`, запуск по уровню сигнала с предзаписью |
| Saved signals | браузер SD-карты, сводка по файлу, список пакетов, повтор, удаление |
| Analyzer | разбор неизвестного пакета: длительности, TE и скорость, кодирование, биты, гистограмма |
| Settings | регион передачи, выбор радио, 5 В на GPIO, подсветка, контраст, DFU, выключение |

Протоколы:

- фиксированный код, приём и повтор: Princeton, CAME, Nice FLO, Holtek HT12X, Linear, GateTX, SMC5326;
- rolling code, только опознавание и разбор открытых полей: KeeLoq, Nice FloR-S, Somfy Telis, CAME Atomo.
  Расшифровки нет, передача невозможна — у этих протоколов нет кодировщика;
- метеодатчики, только приём: Nexus-TH, GT-WT02, inFactory, LaCrosse TX141THBv2, Acurite 592TXR.

Пометка `(exp)` на экране означает, что протокол ещё не проверен на достаточном числе записей.
Метеодатчики проверены только на синтетических сигналах.

Модуляции: AM650, AM270, FM238, FM476. Файлы `.sub` (RAW и Key) совместимы с официальной прошивкой.

### Передача

Передаётся только то, что вы сохранили сами: RAW-записи и фиксированные коды. Пока в настройках
не выбран регион, передача выключена. Перед каждой передачей частота сверяется с разрешёнными
диапазонами региона (EU/RU: 433.05–434.79 и 868.15–868.55 МГц).

## Внешний модуль CC1101

Поддерживается внешний модуль со своей антенной на гребёнке GPIO. Распиновка та же, что
у официальной прошивки, поэтому подходят готовые платы для Flipper.

| CC1101 | Вывод Flipper | Контакт гребёнки |
|---|---|---|
| MOSI | PA7 | 2 |
| MISO | PA6 | 3 |
| CSN | PA4 | 4 |
| SCK | PB3 | 5 |
| GD0 | PB2 | 6 |
| GND | — | 8 |
| 3V3 | — | 9 |

В настройках «Radio»: Auto (внешний модуль, если он отвечает; иначе встроенный), Internal,
External. Активное радио показано в строке состояния: `INT` или `EXT`. Модулям с усилителем
нужно питание 5 В — пункт «5V on GPIO», по умолчанию выключен.

В режиме Auto прошивка при старте кратко опрашивает контакты 2–5. Если к гребёнке подключено
что-то другое, выберите Internal.

## Сборка

Нужны `cmake`, `ninja`, `gcc`, `python3` и для прошивки `gcc-arm-none-eabi`:

```sh
sudo apt install cmake ninja-build gcc python3 gcc-arm-none-eabi libnewlib-arm-none-eabi dfu-util
```

Прошивка:

```sh
cmake -S . -B build/stm32 -G Ninja -DCMAKE_TOOLCHAIN_FILE=cmake/arm-none-eabi.cmake
ninja -C build/stm32            # build/stm32/firmware.bin и firmware.dfu
```

Тесты, анализатор и симулятор на ПК:

```sh
tools/fetch_test_vectors.sh     # эталонные записи, один раз
cmake -S . -B build/host -G Ninja
ninja -C build/host && (cd build/host && ctest)
```

## Прошивка устройства

1. Переведите Flipper в режим DFU: зажмите LEFT + BACK до перезагрузки, отпустите BACK,
   LEFT держите ещё несколько секунд. Экран останется тёмным.
2. Подключите USB и выполните `tools/flash.sh` (это `dfu-util -a 0 -s 0x08000000:leave -D firmware.bin`).

Из работающей Flipper OS 2 в DFU можно попасть через Settings → Reboot to DFU.
Файл `firmware.dfu` предназначен для установки через qFlipper («Install from file»); этот путь не проверен.

### Возврат на официальную прошивку

Войдите в DFU и нажмите Repair в qFlipper.

### Если прошивка не запускается

- LEFT, зажатая при включении или перезагрузке, всегда ведёт в DFU: эта проверка выполняется
  первой, до любого другого кода.
- LEFT + BACK на 1.5 с перезагружает устройство. Если прошивка зависла, через 16 секунд её
  перезапустит сторожевой таймер.
- При сбое на экране появляется «Firmware stopped» с адресом ошибки; BACK — перезапуск, LEFT — DFU.
  Те же сведения выводятся в UART (контакт 13, 115200 бод).
- Аппаратный загрузчик не зависит от прошивки: по документации Flipper нужно держать OK + BACK
  30 секунд, отпустить BACK, затем OK.

Прошивка не пишет во Flash и не трогает option bytes и область радиостека. Настройки хранятся
на SD-карте в `/fos/settings.txt`.

## Управление

- Везде: BACK — назад, LEFT + BACK 1.5 с — перезагрузка.
- Receiver: UP/DOWN — история, OK — подробности или анализ неизвестного сигнала, LEFT — частота,
  модуляция и перебор частот, долгое RIGHT — очистить историю. В подробностях: OK — сохранить, RIGHT — отправить.
- Radio config: LEFT/RIGHT — следующая частота из списка, удержание — шаг 10 кГц.
- Spectrum: LEFT/RIGHT — сдвиг, UP/DOWN — полоса, OK — удержание пиков, долгое OK — в приёмник на частоте пика.
- Frequency finder: UP/DOWN — порог срабатывания, OK — запомнить найденную частоту.
- RAW recorder: OK — старт и стоп, UP/DOWN — порог запуска, LEFT — настройки радио.
- Analyzer: LEFT/RIGHT — страницы.

## sublab: разбор записей на ПК

Тот же движок, что в прошивке, из командной строки:

```sh
build/host/sublab capture.sub        # сводка, распознанные сигналы, разбор неизвестных
build/host/sublab -a capture.sub     # анализ каждого пакета
build/host/sublab -p capture.sub     # длительности импульсов
```

Для неизвестного пакета выводятся группы длительностей, TE, скорость, предполагаемое кодирование,
биты и отличия от предыдущего пакета.

## Симулятор

`build/host/fos_sim` выполняет те же экраны на виртуальном железе по сценарию нажатий:

```sh
mkdir -p sim_out/sd/subghz
build/host/fos_sim emitter:433920000:-48 down ok wait:2500 shot:spectrum
python3 tools/sim_shots.py sim_out sim_out/sheet.png
```

Команды перечислены в начале `platform/host/sim.c`.

## Устройство проекта

```
core/                 форматирование строк, кольцевой буфер, события кнопок
subghz/               пакетизатор, протоколы, анализатор, .sub, пресеты CC1101, регионы
drivers/              драйвер CC1101 (общий для встроенного чипа, внешнего модуля и тестов)
hal/                  интерфейсы железа: экран, кнопки, питание, радио, файлы
ui/                   кадр 128×64, шрифты
app/                  менеджер экранов, настройки, приёмный конвейер, шлюз передачи
apps/                 экраны
platform/stm32wb55/   Flipper Zero: старт, тактирование, шины, экран, питание, радио, SD
platform/host/        симулятор для ПК
tools/                sublab, генератор шрифтов, прошивка, загрузка зависимостей
tests/                модульные и сквозные тесты
third_party/          заголовки CMSIS (ARM, ST; Apache-2.0) и FatFs (ChaN; лицензия в ff.c)
```

Операционной системы реального времени нет: один цикл событий и прерывания. Фронты сигнала
отмечаются по времени в прерывании и складываются в кольцевой буфер; главный цикл делит поток на
пакеты и отдаёт их декодерам.

## Чек-лист первой прошивки

Проверяйте по порядку и сообщайте, на каком шаге поведение расходится с описанием.

1. После прошивки загорается подсветка и появляется меню «Flipper OS 2».
2. Кнопки: UP/DOWN двигают выделение, OK открывает экран, BACK возвращает.
3. В строке состояния виден заряд батареи; в Settings → Battery — проценты и напряжение.
4. Settings → Radios found показывает `INT`.
5. Spectrum: рядом с работающим брелоком появляется пик на его частоте.
6. Frequency finder показывает частоту брелока.
7. Receiver распознаёт брелок с фиксированным кодом.
8. RAW recorder создаёт файл на SD, он виден в Saved signals.
9. После выбора региона повтор сохранённого сигнала срабатывает на вашем приёмнике.
10. Внешний модуль: Settings → Radio → External, в строке состояния `EXT`, пункты 5–9 повторяются.
11. Settings → Reboot to DFU переводит устройство в DFU; Power off выключает.

## Известные ограничения

- Контраст и тип экрана берутся из заводских данных устройства; при бледной картинке поправьте Contrast.
- Импульсы короче ~250 мкс сглаживаются фильтром приёмника в стандартных пресетах.
- При записи RAW на медленную карту в шумном эфире часть импульсов может теряться.
- CAME 12 бит и Holtek HT12X различаются только длиной паузы между кадрами, поэтому одиночный
  кадр может быть назван любым из двух имён.
